# Johann Strauss Sohn Op. 332 Eljen a Magyar two-hand piano 

This repository contains an MEI encoding of the Polka schnell *Eljen a Magyar*, Op. 332 by Johann Strauss Sohn (Johann Strauss junior) for two-hands piano, following the [first edition by C. A. Spina, n.d. [1869],  Plate Plate C.S. 21.730](https://imslp.org/wiki/Special:ReverseLookup/323180).
